ц* Раньше была проблема по налаживанию связи между несколькими компьютерами
* Все производили разные устройства с разным программным обеспечением
* Это стало толчком к разработке сетевых технологий

* Допустим, у нас есть две полностью разные системы
* NCA - Network Card Adapter - сетевой адаптер
	* Благодаря этому сетевому адаптеру устройства могут связываться
	* Их стандартизация - самый важный момент в связи. Если они стандартизированы, то есть возможность передавать данные между любыми устройствами
* CLI - Comand Line Interface - интерфейс командной строки, пример инструмента для взаимодействия пользователя и платформы

![](MortyD14/Photo/p1.png)

Связь есть, но теперь вопрос - а как заставить запросы исполняться?
* Решение есть - редиректор - специальная часть сетевой ОС, который анализирует запрос и решает, отправить запрос на выполнение в саму ОС (если запрос к локальным ресурсам)

* Также есть вариант отдать часть ресурсов на общий доступ. Но это выделение происходит опционально: если не требуется давать ресурс под общий доступ, то система будет использовать его локального

* Для адаптации запросов использовался сетевой браузер (СБ) - он формирует запрос на ресурсы (какие ресурсы др. устройство может выделить нам) и передает его на сетевой адаптер.
![](MortyD14/Photo/p2.png)

* По итогу получается следующая схема:
	1. ПП отправляет запрос через API
	2. Запрос обрабатывается редиректором:
		* Если запрос использует только локальные запросы - отправляем его в ОС
		* Иначе - передаем "Клиенту" - адаптер ,  превращающий запрос в общий вид (стандартизированный), так называемый NetAPI

* Стоит отметить, что второй уровень оказался недостаточно описательным, поэтому его стали разбивать на два подуровня.

* Когда OSI разработали, под него сразу же сделали все нужные протоколы
* Но к тому моменту уже активно развивался TCP/IP - 4-уровневая модель. В ней уровни уже нумеруются обратно

| Уровень TCP/IP | Название                 | Эквивалент в OSI |
| -------------- | ------------------------ | ---------------- |
| I              | Прикладной уровень       | 5-7              |
| II             | Транспортный уровень     | 4                |
| III            | Сетевой уровень          | 3                |
| IV             | Уровень сетевого доступа | 1-2              |
