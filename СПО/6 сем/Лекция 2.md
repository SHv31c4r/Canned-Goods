# Лексический анализ и регулярные язык

* Лексический анализатор
	* Это фаза компиляции, на которой обрабатывается исходная программа, и в ее тексте выделяются лексемы входного языка.

* Лексема
	* Это простейшая структурная единица языка, состоящая из символов, и не содержащая других структур
	* В ЯП есть такие лексемы, как:
		1. Идентификаторы
		2. Ключевые слова
		3. Константы
		4. Знаки операций
		5. Разделители (разделяют лексемы, но сами таковыми не являются)

* Преимущества лексического анализатора
	* Он не обязателен для компилятора, но дает преимущества:
		1. Сокращается объем обрабатываемой информации. (он просто отбросит все, что ему нахуй не нужно)
		2. Некоторые задачи на его этапе решаются с меньшими затратами по ресурсам (например, задача унарного минуса)
		3. Он может отделять...
		4. Обрабатывает текста исходной программы параллельно с его написанием.

* Как строить лексический анализатор
	1. Как определить границы лексем?
	2. Разработать структуры данных для каждого из типов лексем.
	3. Построить распознаватель языка.

* Определение границ лексем
	* В исходной программе они никак специальным образом не обозначены.
	* И это не так просто, так что одного лексического анализатора для этого недостаточно
	* Так что он должен взаимодействовать с синтаксическим анализатором. Для этого есть два способа:
		1. Последовательный. Он проще и эффективнее, но он ограничен сильнее
		2. Параллельный. Он сложнее, но и ограничений меньше
	* Для решения этой проблемы используется метод большей длины: какая лексема из подходящих более длинная, та и используется.

* Выходные данные лексического анализатора.
	* На выходе будет две таблицы: таблица имен (идентификаторов) и таблица лексем.
	* Таблица имен:
		* В первой находятся только лексемы, определенные разработчиком. 
		* Каждая из них упоминается только один раз. 
		* Используется на всех этапах
	* Таблица лексем:
		* Содержит информацию о всех лексемах
		* Они повторяются столько раз, сколько встречаются
		* Используется только на этапе взаимодействия с синтаксическим анализатором
