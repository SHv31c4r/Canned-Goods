	* Аутентификация тогда осуществляется через ПК, но проверка будет осуществляться на контроллере домена.
		* Если ПК нет в контроллере, то его просто не пропустят.

## Про IPV4
* Размер адреса - 32 бита = 4 байта
* Их решили описывать при помощи октетов - 10-значной расшифровки IP-адреса
* Адрес 0.0.0.0 - специальный адрес, который работает на любом протоколе.

* У каждого ПК может быть >1 сетевого адаптера. А каждый сетевой адаптер может поддерживать до 10 сетевых интерфейсов (своего рода, виртуальный сетевой адаптер). У каждого из интерфейсов должен быть свой IP.

* Реальный IP несет в себе 2 идентификатора (это было сделано для децентрализации):
	* Левая часть (первые две октета) отвечает за номер сети.
	* Правая часть - номер узла.
